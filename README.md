# Wordファイル一括作成

WordテンプレートとExcel・CSVの置換データから、複数のWord文書やPDFをまとめて作成するWindows向けデスクトップアプリです。

Tauri、React、TypeScriptによるデスクトップUIと、PythonによるWord・Excel処理を組み合わせています。Microsoft Wordで作成した既存様式を活用しながら、個別ファイル、結合ファイル、ZIPファイルを作成できます。

## Version

**Ver.1.3.1 数値置換時のフォント修正版**

## 主な機能

### 入力

- Wordテンプレート（`.docx`）の読み込み
- Excel（`.xlsx`、`.xlsm`、`.xls`）の読み込み
- CSV（`.csv`）の読み込み
- Word、Excel・CSV、出力先フォルダのドラッグ＆ドロップ
- 日本語を含むファイル名・フォルダ名への対応
- アプリ起動後のPythonバックエンド・ウォームアップ
- テンプレート選択後の事前解析

### データ確認

- 読込件数、使用件数、除外件数、記入例件数の表示
- 使用データと除外データの切り替え
- 除外理由と元のExcel行番号の表示
- 全列表示と横スクロール
- ヘッダー行とNo.列の固定

### 出力

次の6種類に対応しています。

- 個別Word
- 結合Word
- WordファイルのZIP
- 個別PDF
- 結合PDF
- PDFファイルのZIP

### ファイル名

- 通し番号の付加と桁数指定
- Excel・CSVの任意の列をファイル名へ追加
- 複数列の選択と並べ替え
- Windowsで使用できない文字の自動調整
- 同名ファイルの上書き防止
- 出力ファイル名の事前プレビュー

初期設定は次のとおりです。

```text
通し番号：ON
ファイル名に使用する列：選択なし
```

通し番号をOFFにする場合は、ファイル名に使用する列を1つ以上選択する必要があります。

結合ファイルとZIPファイルは、次の形式で保存します。

```text
テンプレート名_件数件一式.拡張子
```

例：

```text
交付決定通知書_128件一式.docx
交付決定通知書_128件一式.pdf
交付決定通知書_128件一式.zip
```

同名ファイルが存在する場合は上書きせず、末尾に番号を追加します。

```text
交付決定通知書_128件一式_2.pdf
```

### 処理状況

- 進捗バーと進捗率
- 現在件数と全件数
- 現在の処理段階
- 完了、待機中、実行中、失敗の表示
- 高速PDF分割から通常方式へ切り替えた場合の案内

- ライト・ダークテーマ

- 出力先を開く
- 作業内容のリセット
- 完了後も選択内容を維持した連続作成
- キーボードフォーカス表示
- Windowsのアニメーション抑制設定への配慮
- Pythonバックエンドのコマンドラインを非表示化

## 基本的な使い方

### 1. Wordテンプレートを準備

置換したい箇所を、半角の二重波括弧で囲みます。

```text
学校名：{{学校名}}
氏名：{{氏名}}
交付決定額：金{{交付決定額}}円
```

括弧内の文字は、置換データの1行目にある列名と完全に一致させてください。

通知日や回答期限など、すべての文書で同じ値を使用する部分は、半角の`<<`と`>>`で囲みます。

```text
通知日：<<通知日>>
回答期限：<<回答期限>>
担当者：<<担当者名>>
```

役割は次のとおりです。

```text
{{学校名}}    Excel・CSVの行ごとに異なる値
<<通知日>>    作成するすべての文書で共通する値
```

テンプレートを選択すると、共通項目が自動検出されます。メイン画面の「共通項目を入力」から値を入力してください。未入力項目がある場合は文書を生成できません。

推奨：

```text
{{学校名}}
```

避ける表記：

```text
{{ 学校名 }}
```

注意事項：

- 波括弧は半角の`{`と`}`を使用してください。
- プレースホルダーの前後に不要な空白を入れないでください。
- プレースホルダー全体を同じフォント、文字サイズ、装飾にしてください。
- 同じ項目はWord内で複数回使用できます。
- テンプレートは`.docx`形式で保存してください。

### 2. 置換データを準備

Excel・CSVの1行目を列名として読み込み、2行目以降を置換データとして使用します。

| 学校名 | 氏名 | 交付決定額 |
| --- | --- | ---: |
| あいうえお高等学校 | 山田 太郎 | 100000 |
| かきくけこ高等学校 | 佐藤 花子 | 120000 |

注意事項：

- 1行目の列名を空欄にしないでください。
- Wordの二重波括弧内と列名を完全に一致させてください。
- 結合セルは使用しないでください。
- データ途中に説明行を入れないでください。
- 口座番号など先頭ゼロが必要な値は、Excel上で文字列として管理してください。
- 複数シートがある場合は、先頭シートを読み込みます。

### 3. アプリでファイルを選択

1. テンプレートWordを選択
2. ExcelまたはCSVの置換データを選択
3. 出力先フォルダを選択

クリックによる選択と、アプリ画面へのドラッグ＆ドロップの両方に対応しています。

### 4. 共通項目を入力

テンプレートに`<<項目名>>`がある場合は、「共通項目を入力」カードが表示されます。検出されたすべての項目へ値を入力して適用します。

共通項目の値はアプリ終了時および全体リセット時に消去され、次回へ自動保存されません。

### 5. 出力条件を指定

```text
出力形式：Word / PDF
出力方法：個別 / 結合 / ZIP
```

必要に応じて「ファイル名と詳細設定」から、通し番号、ファイル名に使用する列、行の除外条件、数値のカンマ区切り、PDF高速化を変更します。

### 6. 複製を開始

件数と出力ファイル名の例を確認し、「複製を開始」を押します。

処理中は、進捗バー、処理件数、処理段階を表示します。

完了後に「閉じる」を押しても、テンプレート、置換データ、出力先、設定は維持されます。出力形式や出力方法を変更して続けて作成できます。

## 行の除外条件

記入例行と空欄行を、それぞれ独立して設定できます。

```text
1列目に「例」を含む行を除外する：ON / OFF
```

空欄による除外条件は、次から選択できます。

```text
何も除外しない
1列目以外に空欄があれば除外
どこかに空欄があれば除外
1列目以外がすべて空なら除外
指定列がすべて空なら除外
指定列のどれか1つでも空なら除外
```

指定列による条件では、置換データの列名を複数選択できます。除外された行は、データ確認画面の「除外されたデータ」タブで、具体的な除外理由とともに確認できます。データ確認画面には現在の除外条件の概要も表示されます。

## 数値のカンマ区切り

「数値をカンマ区切りにする」を有効にすると、登録したキーワードを列名に含む列の値を、カンマ区切り形式へ整形します。

```text
100000 → 100,000
```

対象キーワードは詳細設定から追加・削除でき、設定内容は自動保存されます。

## PDF出力

PDF出力では、デスクトップ版Microsoft WordのPDFエクスポート機能を使用します。

個別PDFの高速化が有効な場合は、原則として次の流れで処理します。

```text
PDF変換用の結合Wordを作成
↓
Microsoft Wordで結合PDFへ変換
↓
個別PDFへ分割
```

文書構成等により高速分割できない場合は、通常方式へ自動的に切り替えます。

## ウォームアップ

アプリのGUI表示後、Pythonバックエンドをバックグラウンドで準備します。初回起動時のみ10～20秒ほどかかる場合がありますが、その間もテンプレート、置換データ、出力先を選択できます。選択したテンプレートと置換データは、準備完了後に自動確認されます。

準備対象には、pandas、NumPy、openpyxl、python-docx、pypdf、アプリ独自の文書処理モジュールが含まれます。

テンプレート選択後には、Word文書の段落、表、セクション、ヘッダー、フッターを事前確認します。

## GitHub ActionsでWindows版をビルドする

GitHubで次の順に操作します。

```text
Actions
→ Windows build
→ Run workflow
→ Branch: main
→ Run workflow
```

ブラウザを閉じても、GitHub側でビルドは継続します。

ビルド成功後、実行結果のArtifactからWindows用インストーラーをダウンロードします。Artifactの保持期間はワークフロー設定に従います。

## アプリアイコン

次のPNGを原本として、Tauri公式CLIからWindows用アイコン一式を生成します。

```text
src-tauri/icons/icon.png
```

原本は、正方形、RGBA、透明背景対応の高解像度PNGを推奨します。
